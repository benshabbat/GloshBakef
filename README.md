# מסנן תמונות

תוסף Chrome שמסתיר תמונות בעייתיות בזמן גלישה. **כל הניתוח מתבצע מקומית במחשב שלכם** — שום תמונה, כתובת או פרט גלישה לא נשלחים לשום שרת.

## איך זה עובד

שתי שכבות סינון, לפי הסדר:

1. **מילות חסימה** — בדיקה מיידית וזולה של הטקסט סביב התמונה: `alt`, `title`, `aria-label`, כתובת התמונה והקישור העוטף אותה. התאמה מסתירה את התמונה מיד, בלי להריץ את המודל.
2. **ניתוח תוכן** — מודל [nsfwjs](https://github.com/infinitered/nsfwjs) מקומי (MobileNetV2 מעל TensorFlow.js) שרץ על תמונות שנכנסות לשדה הראייה. המודל ארוז בתוך התוסף ולא נטען מהרשת.

**סרטונים נבדקים כמו תמונות, ושוב ושוב.** סרטון אינו תמונה אחת: תמונת התצוגה המקדימה שלו יכולה להיות תמימה לגמרי, והתוכן משתנה תוך כדי ניגון. לכן התוסף מצלם את הפריים שהסרטון מציג בפועל, בודק אותו, ובודק שוב כל כמה שניות כל עוד הסרטון מתנגן מול העיניים. סרטון שנחסם גם מושהה ומושתק — טשטוש לבדו לא עוצר פסקול.

תמונה או סרטון שלא ניתן לבדוק — למשל כאלה שהדפדפן לא הצליח לפענח — **נשארים גלויים**. זו התנהגות מכוונת: חסימה בכל כישלון בדיקה הייתה מטשטשת חלקים גדולים מהאינטרנט.

## התקנה

`dist/` נבנה מקומית ואינו נשמר ב־git, ולכן צריך לבנות לפני הטעינה:

```bash
npm install
npm run build
```

אחר כך:

1. פתחו `chrome://extensions`.
2. הפעילו **Developer mode** (מתג בפינה).
3. **Load unpacked** ← בחרו את תיקיית הפרויקט הזו, זו שיש בה את `manifest.json`. לא את `dist/` ולא את `src/`.
4. נעצו את התוסף לסרגל הכלים: לחצו על אייקון הפאזל 🧩 ואז על סיכת הנעיצה ליד "מסנן תמונות". בלי זה האייקון מוסתר, ואיתו גם מונה החסימות והחלון הקופץ.
5. רעננו לשוניות שכבר היו פתוחות. סקריפט התוכן נכנס רק בטעינת דף חדשה, ולכן בלשוניות ותיקות התוסף פשוט לא יהיה שם.

דרוש Chrome 116 ומעלה.

## השימוש הראשון — מה קורה בפועל

אין אשף התקנה ואין מסך פתיחה. אחרי הטעינה התוסף כבר פעיל בכל האתרים עם הגדרות ברירת המחדל, וזה מה שרואים:

**בדף עצמו.** ברגע שדף נטען כל התמונות מטושטשות קלות (12px), עוד לפני שהן נצבעו במלואן. הטשטוש הזה חולף מעצמו תוך שבריר שנייה, כשכל תמונה מקבלת החלטה. זו ההגדרה "הסתרה עד לבדיקה", והיא קיימת כדי ששום דבר לא ייחשף לרגע לפני שנבדק. אם ההבהוב מפריע — אפשר לכבות אותה בהגדרות, במחיר הזה שתמונה עלולה להיראות לרגע לפני שהוסתרה.

**תמונה שנחסמה** נראית אחרת לגמרי: טשטוש כבד, גווני אפור, מסגרת מקווקוות ירוקה ופסים אלכסוניים ברקע. לחיצה עליה חושפת אותה עד סוף הגלישה בדף (רענון מחזיר אותה למצב מוסתר). קוראי מסך מקבלים "תמונה הוסתרה על ידי מסנן התמונות" במקום ה־`alt` המקורי, שנשמר ומוחזר בחשיפה. **סרטון שנחסם** מקבל את אותה חזות, ובנוסף מושהה ומושתק; לחיצה עליו חושפת אותו ומחזירה אותו לניגון אם הוא ניגן קודם.

**על האייקון בסרגל** מופיע תג ירוק עם מספר — כמה תמונות וסרטונים מוסתרים כרגע בלשונית הזו, כולל כאלה שבתוך iframes. הוא מתאפס בכל ניווט. אין תג = לא הוסתר כלום בדף.

**לחיצה על האייקון** פותחת חלון קופץ עם ארבע פעולות: מתג ראשי, מתג "סינון באתר הזה" (מוציא את האתר הנוכחי מהסינון לתמיד), שלוש רמות חומרה, וכפתור "חשיפת הכל בדף הזה" למקרה שהמסנן הגזים. "הגדרות מתקדמות" פותח את דף ההגדרות המלא.

**עניין של תזמון.** הבדיקה הראשונה אחרי הפעלת הדפדפן איטית יותר מהשאר: באותו רגע נטענים TensorFlow והמודל למסמך ה־offscreen. משם והלאה הבדיקות מהירות, ותוצאות נשמרות במטמון לפי כתובת תמונה. אחרי חמש דקות בלי בדיקה המסמך נסגר כדי לפנות זיכרון, והבדיקה הבאה משלמת שוב על הטעינה. תמונות נבדקות רק כשהן מתקרבות לשדה הראייה, לא כל הדף בבת אחת.

## איך לוודא שהתוסף באמת עובד

הדרך הבטוחה לבדוק היא לחסום משהו תמים בכוונה, דרך שכבת מילות החסימה:

1. אייקון התוסף ← **הגדרות מתקדמות**.
2. בתיבת **מילות חסימה** הוסיפו `wikimedia`. ההגדרה נשמרת לבד אחרי חצי שנייה ("נשמר" יופיע למעלה).
3. פתחו ערך כלשהו בוויקיפדיה, למשל [he.wikipedia.org/wiki/חתול](https://he.wikipedia.org/wiki/%D7%97%D7%AA%D7%95%D7%9C).
4. כל תמונות הערך אמורות להופיע מטושטשות עם המסגרת המקווקוות, ועל האייקון אמור להופיע מספר. לחיצה על תמונה חושפת אותה.
5. חזרה להגדרות ← **שחזור רשימת ברירת המחדל**, ורענון הדף.

זה מוכיח שסקריפט התוכן רץ, שההגדרות מגיעות אליו ושההסתרה והחשיפה עובדות. את שכבת המודל אי אפשר לבדוק ככה — היא מגיבה לתוכן התמונה עצמה. מה שכן אפשר: בדף ההגדרות, בקטע **סטטיסטיקה**, מונה "בדיקות התוכן" גדל בזמן גלישה בדפים עם תמונות. אם הוא זז, המודל באמת רץ. דף עם סרטון מתנגן ידחוף אותו קדימה כל כמה שניות מעצמו — זו בדיקה חוזרת של אותו סרטון.

## מבנה

התוסף רץ בשלושה הקשרים נפרדים, וזה העיקר בארכיטקטורה:

```
src/content/     סקריפט תוכן (~7KB) — מחליט מה לבדוק, מסתיר, חושף
src/background/  service worker  — תור, מטמון תוצאות, תג ספירה, רישום ה־CSS הדינמי
src/offscreen/   מסמך offscreen  — TensorFlow והמודל. עותק אחד לכל הדפדפן
src/shared/      הגדרות והודעות המשותפות לכולם
src/ui/          חלון קופץ ודף הגדרות
```

הניתוח לא רץ בדף. סקריפט התוכן שוקל כ־7KB ורק שולח כתובות לבדיקה; המודל (4.5MB) חי במסמך offscreen יחיד שנוצר לפי דרישה ונסגר אחרי חמש דקות ללא פעילות. כך אף לשונית לא משלמת על טעינת TensorFlow.

מסמך ה־offscreen הוא דף של התוסף, ולכן ה־`fetch` שלו נושא את הרשאות התוסף ואינו כפוף ל־CORS של הדף. זה מה שמאפשר לבדוק תמונות ממקורות חיצוניים. לתמונות שאי אפשר להביא כך (`blob:`, תמונות מאחורי הזדהות) סקריפט התוכן מצלם את האלמנט לקנבס 224×224 ושולח את התמונה המוקטנת.

סרטונים הולכים תמיד בדרך השנייה: אין כתובת שאפשר להביא ממנה "את הפריים הנוכחי", ולכן הפריים מצולם מהאלמנט עצמו. מסיבה זו גם אין להם מטמון — כתובת של סרטון מחזירה תמונה אחרת בכל דגימה, ולכן הבקשה נושאת `cache: false` ותוצאתה אינה נשמרת.

## פיתוח

```bash
npm run build   # אייקונים + שתי החבילות
npm run dev     # אותו דבר, עם מעקב אחרי שינויים
npm test        # בדיקות ללוגיקה הטהורה: מילות חסימה, ניקוד, רשימת היתר, מיגרציה
npm run check   # כל הבדיקות, בתוספת נתיבי manifest, נכסים ב־HTML ותקינות תחביר
npm run icons   # יצירת icons/*.png מחדש
```

אין בדיקות אוטומטיות לדפדפן עצמו — הסינון בפועל נבדק ידנית ב־Chrome.

האייקונים נוצרים בקוד ([scripts/make-icons.mjs](scripts/make-icons.mjs)) ולא נערכים ידנית, אבל כן מקובעים ב־git. כל `npm run build` יוצר אותם מחדש, ולכן שינוי בסקריפט צריך להיכנס לקומיט יחד עם ה־PNG המעודכנים.

אחרי שינוי ב־`src/content/`, ב־`src/offscreen/` או ב־`src/shared/` צריך לבנות מחדש — הדפדפן מריץ את `dist/`, לא את המקור.

## מגבלות

- מילות חסימה תופסות רק תמונות שיש להן סימן טקסטואלי, והן עלולות להסתיר תמונות תמימות. ההתאמה היא על גבולות מילה, כך ש־`sexy` כבר לא תופסת את `essexyachts`.
- המודל טועה לשני הכיוונים. רמת החומרה היא בדיוק הכפתור שמכוונן את האיזון הזה.
- ההגנה אינה חסינה: אפשר לחשוף כל תמונה בלחיצה, וכל אתר ניתן להוצאה מהסינון. זהו מסנן, לא בקרת הורים.

מה שאינו נבדק כלל:

| משטח | מצב |
| --- | --- |
| `<img>`, `<picture>`, `srcset`, תמונות עצלות, החלפות ב־SPA, iframes | נבדק |
| `<video>` | נבדק — הפריים המוצג, שוב כל כמה שניות בזמן ניגון, ותמונת ה־poster כגיבוי |
| סרטונים מוגני DRM | לא נבדק — הדפדפן אינו מרשה לקרוא את הפריימים שלהם. נשארים גלויים, ורק מילות החסימה ותמונת ה־poster חלות עליהם |
| רקעי CSS | מילות חסימה בלבד, ורק כשההגדרה דלוקה |
| Shadow DOM | לא נבדק — `querySelectorAll` אינו חודר shadow roots |
| `<canvas>`, `<svg><image>`, `<object>`, `<embed>` | לא נבדק |
| `chrome://`, חנות התוספים, `view-source:`, מציג ה־PDF | התוסף אינו רץ שם כלל |

## פרטיות

בקשות הרשת היחידות שהתוסף מבצע הן הבאת בתי התמונות שהדף כבר טוען ממילא, ממסמך ה־offscreen, ללא עוגיות (`credentials: "omit"`) ומהמטמון של הדפדפן כשאפשר. אין טלמטריה, אין שרת, ואין קוד שנטען מהרשת — משקולות המודל ארוזות בתוך החבילה בזמן הבנייה.
